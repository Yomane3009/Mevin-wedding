# Mevin-wedding
Invitation for Megha and Alvin's wedding.

A plain static site: `index.html`, `styles.css` and `script.js`, with no build step.
Open `index.html` in a browser to preview it. Vercel deploys it as-is.

Wedding details are in `index.html`. Anything marked `[TBD]` still needs the real
value, including the countdown date (`data-date` on `#countdown`) and the RSVP
email address (`data-email` on `#rsvp-form`).
