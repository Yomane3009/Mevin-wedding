# Coimbatore invitation

A copy of the main invitation for guests in Coimbatore, served at
mevin-invitation-coimbatore.vercel.app by its own Vercel project whose Root Directory
is `coimbatore`. It is self-contained (its own `assets/`), so changes here never touch
the main site and changes to the main site are not copied here.

Differences from the main site:
- Rose-gold theme instead of champagne gold (colours in `styles.css`, petal tint in
  `script.js`, favicon). The blurred backdrop film is re-tinted to match with
  `sh tools/make_backdrop.sh coimbatore c98f86`.
- Reception at Sri Sai Vivaha Mahal, Uppilipalayam, Coimbatore, 6.30 PM onwards.
- Its own share thumbnail, `assets/share.jpg`.

RSVPs go to the same Google Sheet as the main site.
